U1Hall of Fame only lists comics that still open

Before: 9 live rows; every one opened "No comic here yet → Generate comic" (the paid button) because the comic had expired or predated the current prompt version.

After: the board only lists places whose comic is live (ILiveComicLookup: unexpired and current PromptVersion). Expiry cleanup now also deletes the live row; the blob stays for the weekly archive.

After: each button reports only its own search ("Searching..."), both are disabled while it runs, and the skeleton is a map plus three cards when the map is the remembered view.
