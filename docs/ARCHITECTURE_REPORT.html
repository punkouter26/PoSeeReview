Middleware order

  1. Forwarded headers before anything that reads client IP or scheme.
  2. Exception handler, user-agent guard, correlation enrichment, and Serilog request logging.
  3. Development-only OpenAPI and WebAssembly debugging hooks.
  4. HTTPS redirection skips /health so probes do not get 307s.
  5. Blazor framework files and static files are served before auth.
  6. Routing, authentication, authorization, rate limiting, then mapped endpoints.
  7. Fallback to /api/{**segments} 404 and non-API SPA fallback to index.html.

/_framework opt-outs

The static Blazor boot assets are not business endpoints. They are served by UseBlazorFrameworkFiles() and UseStaticFiles() before auth, so the shell can load anonymously.

The SPA fallback to index.html is explicitly AllowAnonymous(); otherwise the deny-by-default auth policy would 401 the shell before the client can reach /auth/me.
