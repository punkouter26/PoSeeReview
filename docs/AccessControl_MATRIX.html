Access Control Matrix

All user roles mapped to controllers, endpoints, and access levels. Defined for security audit and authorization boundary review. Three roles: Anonymous, Authenticated (Azure AD), Admin (X-Api-Key).

Anonymous — no auth required Authenticated — Azure AD JWT Admin — X-Api-Key header
