Blast Radius Assessment — ComicGenerationService

The ComicGenerationService is the highest-fanout node in the service graph. Refactoring it impacts:

Upstream: GenerateComicCommandHandler, GetCachedComicQueryHandler, ComicsController

Downstream: RestaurantService, AzureOpenAIService, GeminiComicService, ComicTextOverlayService, BlobStorageService, ComicRepository, LeaderboardService, Application Insights

Tests impacted: All comic generation unit/integration tests, telemetry metric names, SAS URL generation, cache-hit logic.
